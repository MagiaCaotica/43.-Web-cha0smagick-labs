📋 How to Create These Emails in MailerLite

  1. Log in at dashboard.mailerlite.com
  2. Go to Workflows → Click the existing EN automation (Lead Magnet Auto-Responder)
  3. The automation currently has: Trigger → Email 1
  4. Click the ⚡ icon between Email 1 and the End node → Add time delay → 3 days
  5. Drag a new Email action → Paste Email 2 content above
  6. Add another time delay → 4 days (so total = day 7)
  7. Drag another Email action → Paste Email 3 content above
  8. Click Save → Activate if not already active

The sequence structure should be:

[Trigger: Completes EN form] → [Email 1: Welcome+PDF] → [Wait 3 days] → [Email 2: Free Tools] → [Wait 4 days] → [Email 3: Collection Offer] → [End]

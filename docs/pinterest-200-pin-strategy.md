## Batch Generation Pipeline

### Step 1: Canva Template
Create ONE Canva template (1000x1500 px):
- Dark background (gradient from #0a0a0a to #111)
- Gold accent border (#c0a060)
- White/gold text
- Space for featured image (app screenshot or occult symbol)
- Logo at bottom: cha0smagicklabs.com

### Step 2: Text Variations
For each pin, vary:
- Title (keep under 60 chars for readability)
- Description (2-3 lines, benefits-focused)
- Hashtags (3-5 per pin)
- Call-to-action button/link

### Step 3: Scheduling Using Tailwind
1. Sign up: tailwindapp.com (free for 150 pins/mo, $17.99/mo for unlimited)
2. Connect Pinterest business account
3. Upload all 200 pins at once into Tailwind drafts
4. Set queue: 7 pins/day, spread across peak hours (1-3 PM, 7-9 PM EST)
5. Tailwind auto-schedules based on optimal times

### Step 4: Manual Upload Alternative
If Tailwind not used:
- Upload 7 pins every day via co.pinterest.com/pin-creation-tool/
- Use batch: upload multiple images at once, fill details one by one
- Time: ~15 minutes/day for 7 pins

## Maxims for Pin Virality

1. **Vertical only**: 1000x1500 px minimum (2:3 ratio)
2. **Text overlay**: Big, bold, readable at thumbnail size
3. **Dark aesthetic**: Matches occult niche — moody images convert
4. **Benefit-driven title**: "How to [achieve X]" not "About [topic]"
5. **Rich Pins**: Ensure og:meta tags are correct on all pages
6. **Fresh pins daily**: Pinterest algorithm favors consistent new content
7. **Board organization**: Each board focused on ONE subtopic
8. **Description keywords**: Include searchable terms naturally

Alphabet Selection Protocol

  1. Identify Entity Type: What class of entity? (Ancestral → Futhark. Angelic → Enochian. Earth/Nature → Theban. General → English. Root/Ancestral → Phoenician.)
  2. Select Primary + Overlay: Primary = English (base). Overlay = chosen alphabet. Use both simultaneously for cross-reference.
  3. Cross-Reference Protocol: Same question in English + overlay. Compare letter-by-letter. Convergence = high confidence. Divergence = ambiguity flag.

Board Configuration for Multi-Alphabet

Physical board: Standard English letters as base. Overlay cards/sheets for each alphabet (Theban, Futhark, Phoenician, Enochian) placed adjacent or as overlays. Digital board (app): Toggle alphabet layers with single tap. Ouija Cazadora app supports all 5 alphabets with toggle.

Techniques: Two-Station, Single-Operator, Group Protocols

Three operational modes. Each has distinct calibration, signal-to-noise profile, and use case.

1. Single-Operator (Blindfolded Solo) — Precision Mode

Use Case: Precision work, entity identification, deep trance, personal gnosis.

  1. Setup: Operator blindfolded. Assistant records letters silently.
  2. Calibration: 3-point (YES/NO/HELLO) + ideomotor baseline (blindfolded known-answer test).
  3. Protocol: Operator holds planchette solo. Assistant records silently. No verbal feedback during session.
  4. Advantages: Eliminates group-mind noise. Maximum operator focus. Ideomotor baseline cleanest.
  5. Disadvantages: No real-time verification. Higher fatigue. Requires assistant.

2. Two-Station (Questioner + Pointer) — Verification Mode

Use Case: Group work, teaching, verification-heavy sessions, client work.

  1. Setup: Questioner (asks, records). Pointer (holds planchette, silent). Roles can swap.
  2. Calibration: Both operators calibrate. 3-point calibration together.
  3. Protocol: Questioner asks aloud. Pointer moves planchette. Questioner records. Swap roles mid-session for cross-verification.
  4. Advantages: Built-in verification (pointer blind to question). Reduces ideomotor contamination. Shared load.
  5. Disadvantages: Group-mind noise possible. Pointer may be influenced by questioner's micro-expressions.

3. Group Protocol (3+ Operators) — Collective Mode

Use Case: Egregore work, group egregore seeding, collective divination.

  1. Setup: Circle of 3-7 operators. One planchette, all fingers light touch.
  2. Calibration: Group 3-point calibration. Group ideomotor test (all blindfolded, same known question).
  3. Protocol: Designated questioner asks. All touch planchette. Designated scribe records.
  4. Group Calibration: Pre-session group ideomotor baseline. Post-session individual logs compared.
  5. Egregore Seeding: If entity manifests consistently across operators → group egregore forming.

Interpretation Methods: Letter, Numerical, Cross-Reference, Sigil

The raw output is letters. The art is in the translation. Four interpretation layers.

1. Letter-Level Interpretation (Direct)

Read the spelled message directly. Apply standard linguistic analysis: anagrams, acrostics, word boundaries, phonetic approximations. Most direct but lowest depth.

2. Numerical Interpretation (Gematria/Isopsephy)

Convert letters to numbers (A=1, B=2... or Hebrew/Greek values). Sum message values. Cross-reference with numerological tables.

3. Cross-Reference Interpretation (Multi-Alphabet)

Same message through multiple alphabets. Convergence = confirmation. Divergence = nuance/ambiguity.

  1. Spell message in English.
  2. Translate to Phoenician / Theban / Futhark / Enochian.
  3. Read each version. Convergence = high confidence. Divergence = ambiguity flag.
  4. Cross-reference key terms across alphabets.

4. Sigil Interpretation (Visual/Symbolic)

Trace the planchette's path as a sigil. The movement path IS a sigil.

  1. Trace the complete movement path on paper/overlay.
  2. Simplify to essential strokes (Spare method: remove redundant lines).
  3. Interpret as sigil: shapes, intersections, directions, enclosures.
  4. Charge the path-sigil for ongoing work.

Calibration & Validation: PSI GYM, Information Test, Blind Protocols

Without calibration, you have no discrimination. These protocols establish your session's truth baseline.

1. The 3-Point Calibration (Mandatory Every Session)

  1. "Show me YES" → Record speed, pressure, trajectory, pattern, time.
  2. "Show me NO" → Record speed, pressure, trajectory, pattern, time.
  3. "Show me HELLO" → Record entity signature (speed, pressure, trajectory, personality).

2. The Ideomotor Baseline Test

  1. Blindfold operator (or close eyes).
  2. Ask known-answer question: "Is my name [Name]?"
  3. Record movement signature: speed, pressure, trajectory, pattern.
  4. This = YOUR ideomotor signature. Match during session = operator, not external.

3. Environmental Baseline

  1. Planchette on board, NO HANDS.
  2. Wait 60 seconds. Record any movement (speed, direction, pattern).
  3. This = environmental baseline (drafts, vibration, board warp). Match during session = artifact.

4. The Information Test (Gold Standard)

The ONLY way to prove external agency vs ideomotor:

  1. Prepare 5 verifiable questions with UNKNOWN answers to operator.
  2. Examples: "What object is in my pocket?" "What is the license plate outside?" "What did I eat 3 days ago?"
  3. Ask during session. Record answers. Verify post-session.
  4. Accuracy >70% = external probable. <50% = ideomotor probable.

5. Blind Test Protocol

  1. Operator blindfolded. Assistant records.
  2. Mix known-answer questions (control) with unknown (test).
  3. If unknowns >chance accuracy → external signal probable.

Safety Protocols: Container, Interference, Termination

  1. Physical Space: Clean, salted, incensed. Protective sigils at 4 corners. Crystal at center (clear quartz/black tourmaline).

Frequently Asked Questions

Is ouija board practice dangerous?

With proper preparation and technique, ouija work is as safe as any other divination practice. The key is proper container (protective sigils, crystal, grounding), clear intent, and strict closure protocols. The Ouija Cazadora PDF provides complete safety protocols.

How do I distinguish between my subconscious and genuine spirit communication?

1) Calibration: Establish YES/NO baseline. 2) Information test: Ask verifiable unknowns (only entity could know). 3) Movement quality: Ideomotor = smooth, predictable. Genuine = unexpected speed/pressure/pattern. 4) PSI GYM: clean channel (>28% hit rate) = reliable discrimination.

What alphabets does the Ouija Cazadora support?

Standard English, Phoenician (22 letters), Theban (24 letters), Futhark (24 runes), Enochian (21 letters), custom sigil alphabets. Each adds interpretive layers and cross-referencing capability.

Is single-operator or two-station technique better?

Single-operator (blindfolded) = higher focus, less group-mind noise, ideal for precision work. Two-station (questioner + pointer) = built-in verification, reduces ideomotor contamination, better for group work. Choose based on intent.

How do I close an ouija session properly?

1) 'Session closed. All entities depart.' 2) Remove planchette. 3) 'Circuit closed.' 3) LBRP/banishment. 4) Grounding: salt bath, water, protein, 8h sleep. 5) Journal log. Never leave board open.

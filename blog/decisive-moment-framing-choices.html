The Architecture: Framing = Choice Architecture

A frame is not a perspective — it's the architecture of choice. The same objective reality framed differently produces measurably different decisions. This is not a cognitive bias to overcome; it's the fundamental architecture of human choice.

The Frame Equation: Decision = Frame × Values × Information. Change the frame, change the decision. Same values, same information, different frame = different decision.

The Neuroscience: Frames are pre-conscious pattern matches. The brain matches incoming stimuli to existing frames in ~100ms (before conscious awareness). The frame activates associated values, emotions, and action scripts. Conscious reasoning then rationalizes the frame-driven output.

The Leverage Point: You cannot prevent framing — the brain always frames. But you can consciously select the frame before the decision window closes. This is the Law of Framing: Conscious frame selection = choice architecture mastery.

The Frame Equation: Decision = Frame × Values × Information. Same values + same information + different frame = different decision. Frame is the multiplier. Master the frame, master the decision.

Phase 1: Frame Audit Protocol — Name, Assume, Test

Every decision begins with a frame audit. This 3-step protocol takes 60 seconds and converts unconscious framing into conscious choice.

Step 1: Name the Current Frame (10 seconds)

Before deciding, state aloud or in writing: "I am currently framing this as..."

FRAME NAMING TEMPLATE: ====================== Decision: _______________________________________ Current Frame: "I am framing this as ____________________________" Frame Type: [ ] Gain/Loss [ ] Action/Inaction [ ] Identity [ ] Resource [ ] Time [ ] Social Trigger: What prompted this decision? _______________________________________

Step 2: List 3 Hidden Assumptions (20 seconds)

Every frame carries assumptions. Excavate them:

ASSUMPTION EXCAVATION: ====================== Assumption 1: _________________________________________________________ Evidence For: ___________ | Evidence Against: ___________ If Inverted: "What if the opposite were true?" _________________________ Assumption 2: _________________________________________________________ Evidence For: ___________ | Evidence Against: ___________ If Inverted: ________________________________________________________ Assumption 3: _________________________________________________________ Evidence For: ___________ | Evidence Against: ___________ If Inverted: ________________________________________________________

Step 3: Test Frame Validity (30 seconds)

For each assumption, apply the Validity Test:

  1. Empirical Check: "Is this empirically true? What data supports/contradicts it?"
  2. Inversion Test: "What if the opposite were true? How would the decision change?"
  3. Values Alignment: "Does this assumption serve my stated values, or my fears?"
  4. Portfolio Check: "Does this frame hold across my decision portfolio, or just this instance?"

Phase 2: Reframing Toolkit — 7 Standard Refames

Once you've audited the frame, apply the appropriate reframe. These 7 reframes cover 90% of framing traps.

TrapOriginal FrameReframeNew Question
Loss Aversion"If I fail, I lose $X""If I don't try, I guarantee $0. Trying has EV = probability × payoff.""What's the expected value of trying vs not trying?"
Status Quo"Better not change things""Status quo is a decision. Not choosing IS choosing the status quo.""If I weren't already doing this, would I start?"
Sunk Cost"I've invested so much already""Past investment is gone. The question: Is the NEXT increment worth it?""If I weren't invested, would I put in the next dollar/hour?"
Narrow Framing"Should I do A or B?""What are ALL my options? What does a portfolio approach look like?""What are 5 options? How do they work as a portfolio?"
Identity Trap"I'm not the kind of person who...""Identity is a prediction, not a prison. 'I am someone who [new behavior]'.""What would the person I'm becoming do?"
Scarcity Mindset"I don't have enough time/money""Constraints drive creativity. How do I get 10x output from current resources?""How would I solve this with 10x the resources? Now do 1/10th of that."
Fear of Regret"What if I regret this?""Regret of action fades. Regret of inaction compounds. Which regret can I live with?""In 10 years, which regret will sting more: trying and failing, or never trying?"

The Reframe Protocol (60 Seconds)

REFRAME PROTOCOL: ================= 1. NAME: "I'm framing this as [current frame type]" 2. EXCAVATE: List 3 assumptions 3. INVERT: For each assumption, ask "What if the opposite were true?" 4. GENERATE: Write 3 alternative frames 5. TEST: Score each frame 1-10 on: Values alignment, Outcome probability, Regret minimization 6. CHOOSE: Select highest-scoring frame 6. ACT: Decide within the chosen frame

The 2-Second Rule for Reversible Decisions

Most decisions are reversible and low-stakes. For these, speed is the signal. The 2-Second Rule:

2-SECOND RULE: ============== IF: Decision is reversible AND stakes < $100 THEN: Decide in 2 seconds. No frame audit. No revisit. RATIONALE: Reversible decisions burn time in proportion to fear, not stakes. SPEED TRAINS THE MUSCLE. The cost of a wrong reversible decision = near zero. The cost of deliberation paralysis = massive over a lifetime.

When NOT to Use the 2-Second Rule

  • Irreversible decisions (contracts, surgery, firing, marriage)
  • High stakes (>$1000 or affecting others' wellbeing)
  • Decisions setting precedent for future decisions
  • Decisions involving ethical/moral dimensions

Portfolio Framing: Single Decision vs Portfolio View

Narrow framing = evaluating each decision in isolation. Portfolio framing = evaluating decisions as a set. The portfolio frame dramatically improves outcomes by diversifying risk and aligning with long-term values.

The Portfolio Frame Shift

"Should I say yes to this request?""How does this yes fit my monthly capacity budget?"Protects capacity, prevents overcommitment

Frequently Asked Questions

What is cognitive framing and why does it matter?

Framing is how you mentally structure a choice — the lens through which you view options. The same objective facts framed differently produce different decisions. Framing is not bias to overcome; it's the architecture of choice. Conscious frame selection = choice architecture mastery.

What are the most common framing traps?

1) Loss aversion framing (losses loom larger than gains). 2) Status quo bias (current state framed as safe). 3) Sunk cost framing (past investment frames future choice). 4) Narrow framing (single decision vs portfolio view). 5) Default framing (accepting the presented frame without examination).

How do I practice conscious framing?

The Frame Audit Protocol: 1) Name the current frame aloud. 2) List 3 assumptions. 3) Generate 3 alternative frames. 4) Test each against values. 5) Choose consciously. Practice on 5 decisions/day. 14-day cycle for automation.

Can framing be used manipulatively?

Framing is neutral architecture. Used on yourself = self-leadership. Used on others without consent = manipulation. The ethical line: Does the frame serve the other person's values, or your agenda? Transparent framing = 'Here's how I'm framing this, and why.' Opaque framing = manipulation.

How does framing interact with the Response Gap?

The Response Gap is the 300ms window between stimulus and conscious response. Framing operates IN this gap. A well-practiced frame auto-activates in the gap, shaping perception before conscious choice. The Response Gap training expands the window; Framing mastery shapes what happens inside it.
